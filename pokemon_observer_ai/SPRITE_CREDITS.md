# Bundled follower-sprite provenance

The user explicitly stated they have permission to package the three requested sprites from:

`https://github.com/gamecorner-033/PokePCFollowers`

The upstream repository later removed its `assets/` directory from the default branch, so these files were retrieved from the repository's own historical commit where the assets were present:

- Source commit: `dfe64d4fcee4833aa79ec7357c2146455b679d81`
- Bulbasaur: `assets/sprites/follower_001.png`
  - Git blob: `396ab16dde7575aa8ff2afe90bfe2fb9fef81aa2`
- Charmander: `assets/sprites/follower_004.png`
  - Git blob: `57952b1d876fbc01b106fa1850bf585ac3017976`
- Squirtle: `assets/sprites/follower_007.png`
  - Git blob: `99d25d64d835084bf04f351b3e33246596f7b80a`

The files in this mod are byte-for-byte matches to those Git blobs.

The PokePCFollowers README credits the overworld sprite work to ShockSlayer and the makers of Pokemon Crystal Clear. This mod preserves that attribution and makes no additional ownership claim over those sprite assets.
